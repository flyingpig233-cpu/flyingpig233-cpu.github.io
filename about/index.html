你好，欢迎来到飞猪手记。

这里是 FlyingPig 的个人博客，一个用来记录技术探索、项目实践与日常思考的地方。

比起匆匆给出结论，我更喜欢保留探索的过程。一件事为什么这样做，一段代码如何从想法变成现实，一个问题又怎样改变了原先的理解——这些细节，值得有一个安静的位置。

写一点，也做一点

文字帮助整理思考，作品让想法落地。你可以在这里读手记，也可以去体验已经上线的几何课堂与课程助手。它们都保留了独立的访问地址。

关于这个小站

它以简单、安静、便于阅读为出发点。没有复杂的装饰，让注意力回到文字；也没有必须遵守的更新频率，让内容按自己的节奏生长。

文章会随新的理解继续完善。如果发现问题，或对某个作品有想法，欢迎通过 GitHub 交流。
